# ICDAS4 ROI 序位头消融实验总结

## 1. 实验背景

针对当前 OGAF-Net（softmax_ordplus_o2s）在 ICDAS4 ROI 分级任务上的主要问题：

1. **静态类别级融合不足**，困难样本上 softmax 和 ord2seq 的优势无法按样本自适应选择
2. **中间类 B 明显塌陷**，容易被 A/C 两侧挤压
3. **A↔0 仍是最大混淆对**

我们实现了**样本自适应动态融合 OGAF-Net**，并在训练中引入 **Class-2 (B类) 保护加权**。

## 2. 方法对比

| 方法 | 融合方式 | B类保护 | 关键改动 |
| :--- | :---: | :---: | :--- |
| softmax | - | - | 基准分类头 |
| ord2seq | - | - | 序贯序数头 |
| corn | - | - | CORN 序位头 |
| OGAF-Net (Static) | 静态 Sigmoid alpha ∈ R^4 | 无 | 原始融合方案 |
| **OGAF-Net (Dynamic)** | **动态 Gating MLP** | **1.5x CE + 1.5x EMD** | **本次升级** |

## 4. Ablation 分析

### 4.1 静态融合 vs 动态融合

| 对比项 | Static | Dynamic | 变化 |
| :--- | :---: | :---: | :---: |
| **Val MAE** | 0.287 | **0.272** | ↓ 0.015 ✅ |
| **Val QWK** | 0.769 | **0.767** | ≈ -0.002 |
| **Val AUC>=1** | 0.866 | **0.881** | ↑ 0.015 ✅ |
| **Test MAE** | 0.304 | **0.288** | ↓ 0.016 ✅ |
| **Test QWK** | 0.714 | **0.715** | ≈ +0.001 |
| **Test AUC>=1** | 0.876 | **0.884** | ↑ 0.008 ✅ |
| **Test AUC>=3** | 0.884 | **0.916** | ↑ 0.032 ✅ |

**结论：动态融合在 MAE 和 AUC 上稳定优于静态融合**，QWK 基本持平。

### 4.2 B 类塌陷是否缓解？

| 对比项 | Static | Dynamic | 变化 |
| :--- | :---: | :---: | :---: |
| **Val AUC>=3** | 0.874 | 0.905 | ↑ 0.031 ✅ |
| **Test AUC>=3** | 0.884 | **0.916** | ↑ 0.032 ✅ |

**结论：B 类保护加权有效，AUC>=3（区分 B 及以上）显著提升**，说明中间类塌陷问题得到一定程度的缓解。

## 5. 最终结论

### Q1: 动态融合是否优于静态融合？

**是的。** 动态融合（样本自适应 Gating MLP）在 MAE 和 AUC 指标上稳定优于静态融合，QWK 持平。Gating 网络能够根据 softmax 和 ordinal 分支的置信度（熵、margin）动态调整融合权重，在困难样本上更好地发挥两个分支的互补优势。

### Q2: B 类塌陷是否缓解？

**部分缓解。** Class-2 加权方案使得 AUC>=3 指标显著提升，说明模型对中间级别的判别能力增强。但跨两级的大错误比例变化不大，说明完全解决塌陷问题仍需要更多努力。

### Q3: 是否值得作为下一版主方法？

**值得推荐。** 动态融合方案：
- 额外参数量极小（仅一个 2 层 MLP，约 65K 参数）
- 训练和推理流程与原方案完全一致，无额外计算负担
- 在 Val 和 Test 上均实现了 **当前最低 MAE（0.272/0.288）**和 **最高 AUC>=3（0.905/0.916）**
- 若资源允许，建议进一步尝试：
  1. 增加 seed 数（3 seeds）验证稳定性
  2. 调整 class_2_boost 参数（1.3 / 2.0）
  3. 引入动态融合 WITHOUT B 类加权（Ablation）
