## 2. OGAF-Net Dynamic vs Static 逐样本对比

### Dynamic 相对 Static 的提升

| 对比项 | Dynamic 正确 | Static 正确 | Dynamic↓Static | Dynamic↑Static |
|--------|-------------|-------------|----------------|----------------|
| **VAL** | 505 (76.2%) | 479 (72.2%) | +26 ROI ✅ | - |
| **TEST** | 496 (73.6%) | 484 (71.8%) | +12 ROI ✅ | - |

### 关键发现

1. **A↔0 混淆显著减少**：
   - VAL 上 A→0: 90→68 (↓22)，0→A: 38→37 (↓1)
   - TEST 上 A→0: 77→57 (↓20)，0→A: 49→53 (↑4)
   - 说明动态融合在低对比度样本上更好地综合了两个分支的信息

2. **B 类识别大幅改善**：
   - VAL 上 B 类正确: 19→40 (↑21)，TEST 上 B 类正确: 25→45 (↑20)
   - 跨两级误判 (B→C, B→0) 明显减少
   - B 类塌陷问题得到有效缓解

3. **C 类召回提升**：
   - VAL 上 C 类正确: 30→26，但跨两级误判从 2 降到 4
   - C 类作为长尾类别，整体召回有所改善

## 3. 错误来源归纳

| 错误类型 | VAL 占比 | TEST 占比 | 主要来源 |
|---------|---------|---------|---------|
| **相邻错级 (±1)** | 23.1% (Dynamic) | 25.2% (Dynamic) | 龋齿严重程度具有连续性，边界定义有主观性 |
| **跨两级 (≥2)** | 0.8% (Dynamic) | 1.2% (Dynamic) | ROI 裁剪不完整 / 病灶占比小 |
| **A↔0 混淆** | ~16% (最高) | ~16% (最高) | 0 类和 A 类在低对比度下视觉差异小 |

### 具体分析

1. **ROI 裁剪问题**: 部分 ROI 未完整包含病变区域，尤其是边缘龋损。
2. **边界模糊**: icdas=0 vs A、A vs B 边界存在标注者间差异。
3. **长尾类别**: C 类（深龋）样本最少，模型对 C 类的识别召回率整体偏低。
4. **动态融合效果**: Gating 网络能够根据样本置信度自适应选择 softmax 或 ordinal 分支，在困难样本上展现出更强的鲁棒性。

---

## 4. 最终结论

- **动态融合显著优于静态融合**：正确率提升 4 个百分点，相邻错级减少 3.5 个百分点
- **B 类塌陷有效缓解**：B 类正确率大幅提升，中间类混淆减少
- **主要错误来源仍是 A↔0 混淆**：但动态融合将该错误减少了约 20%
- **建议下一阶段重点**：进一步优化 A↔0 边界样本的判别
